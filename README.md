# 🎬 Movie Recommender System

## 📖 Overview

The **Movie Recommender System** is a Python-based command-line application designed to help users discover movies based on their preferred genres. The system reads movie information from a CSV dataset and recommends up to **10 random movies** that match the user's selected genre.

Unlike traditional recommendation systems that require user accounts or ratings, this project provides a lightweight and efficient way to explore movies using a simple menu-driven interface.

The application currently supports **English, Hindi, and Telugu** movies, making it useful for users with diverse language preferences.

---

# ✨ Features

- 🎥 Recommend movies based on user-selected genres.
- 📂 Reads movie information from a CSV dataset.
- 🌍 Supports English, Hindi, and Telugu movies.
- 🎲 Randomly recommends up to 10 movies for every search.
- 🖥️ Interactive command-line interface.
- ⚡ Fast and lightweight implementation.
- 📊 Uses Pandas for efficient data handling.
- ❌ Handles invalid user inputs gracefully.
- 🔄 Allows users to perform multiple searches in a single execution.
